## 🚀 How to Run / Preview

- **Direct Browser**: Double-click [`index.html`](file:///E:/IceMaster_Project/index.html) in Windows Explorer to open directly in any modern web browser.
- **Local HTTP Server** *(Recommended for full feature fidelity)*:
  ```powershell
  python -m http.server 8080
  ```
  Then visit `http://localhost:8080/` in your browser.
